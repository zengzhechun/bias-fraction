BF 临床应用算法说明 v1

对应论文稿件 v37 · 评估指标 BF（偏倚份额，bias fraction）· 受众：临床医生（无需统计学或模拟研究背景）· 文档版本：2026-08-26
一句话总结：输入一篇文献报告的校准 p 值、BF̂、BF 的 95% 可信区间三件套，算法自动算出"真值由偏倚主导的概率" P(偏倚主导)≈X%，并把结果归到两类四档之一 —— 可作效应证据、混合·假设生成、势均力敌·暂不下结论、不可作效应证据（再加一个 证据不足 兜底）。医生不需要自己判断"窄区间还是宽区间" —— 这是算法内部的计算步骤。

§1 算法要回答的问题

给定一个观察性研究的因果估计，它能不能直接当作"该效应的因果证据"使用？注意：这个工具不替医生开药，也不替临床指南制定者下结论 —— 它只判定这一项观察性估计的可靠性等级。

§2 输入与输出（API 形式）

输入（必填三项）

名称含义取值范围从论文哪里读
校准 p 值
p_cal		 经验校准后的 p 值（OHDSI EmpiricalCalibration）。 0–1 论文方法节"Empirical calibration"段落。
BF̂ 估计
BF_hat		 BF̂ = |μ̂_B| / (|μ̂_B| + ψ̃)。衡量的偏倚份额。 0–1（理论边界） 同一段校准输出，通常与 μ̂_B、ψ̃ 一同报。
BF 的 95% 可信区间
[BF_lo, BF_hi]		 BF̂ 的不确定性区间（plug-in 自 μ̂_B 的 CI）。 0 ≤ BF_lo ≤ BF̂ ≤ BF_hi ≤ 1 同段报为"BF (BF_lo–BF_hi)"或"BF ± half-width"。

输出（一句话 + 两个数）

字段含义示例
判语 verdict 四档之一 + 兜底一档。
可作效应证据 · 混合·假设生成 · 势均力敌·暂不下结论 · 不可作效应证据 · 证据不足 		可作效应证据
P(偏倚主导) ≈ 真值实际落在"偏倚主导"侧的概率（来自模拟研究的统计校正），保留 1 位小数。 P(偏倚主导) ≈ 3.1%
BF̂ 报告值 原样回显，便于论文对照。 BF̂ = 0.33 (0.15–0.50)

§3 算法流程（5 步，伪代码）

INPUT:  p_cal, BF_hat, [BF_lo, BF_hi]
OUTPUT: verdict, P_bias_dom

  1. IF p_cal >= 0.05:
         RETURN (verdict="证据不足", P_bias_dom=null)
     // 第一层：校准 p 不显著 → 信号不存在，停。

  2. CI_half_width = (BF_hi - BF_lo) / 2

  3. BIN = locate_bin(BF_hat)        // 12 段读数桶（x 中心: 0.06, 0.17, 0.26, ...）
         [NB, WB] = lookup_pBD(BIN)   // 从 §6 的模拟查表（12 段读数桶）：窄/宽两个 P(偏倚主导)

  4. P_bias_dom = max(NB, WB)        // 取窄/宽两档的较大值 → 保守判读
     // 这一步就是算法内部"自动处理"窄/宽的关键。
     // 医生完全不需要自己判断。

  5. IF    P_bias_dom <  0.15:  verdict = "可作效应证据"
     ELIF  P_bias_dom <  0.45:  verdict = "混合·假设生成"
     ELIF  P_bias_dom <  0.65:  verdict = "势均力敌·暂不下结论"
     ELSE:                       verdict = "不可作效应证据"

  RETURN (verdict, P_bias_dom)
关键设计："窄/宽"这个概念不暴露给医生。医生提供 BF̂ 区间即可，算法在第 3–4 步自动根据 CI 半宽映射到模拟研究的概率曲线，并取保守值作为最终 P(偏倚主导)。这样临床读者只需懂"BF̂ 越接近 1 = 偏倚越占主导"和"P 值越低 = 信号越稳"两个直觉，不必了解"中位数切两半""Bootstrap 宽度"等模拟方法术语。

§4 阈值的来源（为什么可以信赖这几个数字）

四个阈值 0.05、0.15、0.45、0.65 都来自同一份实证研究 —— 64 万次（640 个条件 × 1000 次重复）模拟。模拟里同时生成了"真值"和"算法判定"，于是可以反过来统计：在某个判定输出下，真值实际落在"偏倚主导"侧的概率是多少。下面把每个阈值的出处说清楚：

阈值控制变量数据来源临床含义
0.05（校准 p） 第一层"信号是否存在"的显著性水平。 沿用统计惯例（与单侧 0.05 同 spirit）。 观测值是否超出零假设 + 已测混杂所能解释的范围。
0.15（P 偏倚主导） "可作效应证据"上限。 模拟中低 BF 段即使宽 CI 仍能维持 P<0.15。 偏倚份额不超过 15%，可放心使用。
0.45（P 偏倚主导） "混合·假设生成"上限。 模拟中 BF 居中段窄 CI 可落入此档。 偏倚份额在 15–45% 之间，方向有信号但强度不够，列为假设生成。
0.65（P 偏倚主导） "势均力敌"与"不可作"的分界。 模拟中高 BF 段即便窄 CI 也几乎全超此阈值。 偏倚份额过半，不能作为因果证据使用。
临床医生不必重做模拟。本算法的全部阈值已经定型。要做的是：把一篇论文报的 p_cal、BF̂、(BF_lo–BF_hi) 三个数填进来，算法就能给出判定。这就是"算法内部自动完成判断、不暴露宽/窄"的好处：即使完全没读过论文模拟的人，也能正确使用本工具。

§5 BF 端点行为可视化 —— 在 BF̂ = 0 和 BF̂ = 1 附近，CI 半宽怎么算

BF̂ 是一个比值，理论范围 [0, 1]，但实际报告的可信区间会被边界"截断"。这是单调变换的固有性质：BF = g(x) = |x|/(|x|+ψ̃) 在 x 接近 0 处斜率极陡，在 x 接近 −ψ̃ 处斜率极平。这意味着：

  • 当 BF̂ 接近 0（偏倚份额很小）：BF̂ 区间下界常贴 0（CI 不会变负），实际可用信息只有上半段。
  • 当 BF̂ 接近 1（偏倚份额几乎完全解释）：BF̂ 区间上界常贴 1（CI 不会超过 1），实际可用信息只有下半段。
  • 当 BF̂ 居中（典型读数 0.2–0.8）：CI 通常对称，半宽 = (BF_hi − BF_lo)/2 即双向都可用。

下面四种情况分别图示。算法在第 3–4 步会自动处理截断，临床医生无需手动校正。

实际可用半区 整段 CI（含截断） BF̂ 点估计 · ① ④ 为典型双向可用情况；② ③ 在 BF 端点处 CI 单方向可用，半宽取单向。这是算法内部取 max(窄,宽) 保守判读的几何来源。

关键结论：医生只读「BF̂ + CI」即可

医生完全不需要自己区分"窄/宽"。BF̂ = 0.05 时 CI 下界被 0 截断、上半区可用；BF̂ = 0.92 时 CI 上界被 1 截断、下半区可用；BF̂ = 0.30 时双向可用。这些差异全部由算法在内部自动处理，输出仍是同一份"判语 + P(偏倚主导)≈X%"，没有任何一步需要医生参与。

  • BF̂ = 0.33

手算演示：

1. p_cal = 0.012 < 0.05  → 进入第二层
2. CI_half_width = (0.50 - 0.15) / 2 = 0.175  → 区间偏宽
3. BIN: BF̂ = 0.33 → 落在第 4 桶（x ≈ 0.329）
4. 查表：第 4 桶 窄档 pBD = 0.0878，宽档 pBD = 0.265
5. P_bias_dom = max(0.0878, 0.265) = 0.265
6. P_bias_dom = 0.265 落在 0.15–0.45 → 混合·假设生成

BF̂ = 0.33 (CI 0.15–0.50)，校准 p = 0.012
混合·假设生成   P(偏倚主导) ≈ 26.5%
解读：偏倚份额约 1/3、信号显著，但 CI 偏宽使真值偏倚主导概率达 26.5%，落在混合区间（15–45%）。建议作为假设生成使用，需更多独立证据支持。

§7 何时不要使用本算法

  • RCT 文献 —— 已经随机化，本工具不适用；按 RCT 标准判读即可。
  • 未做经验校准的观察性研究 —— 必须先用 OHDSI EmpiricalCalibration 校准后再用本算法；未校准的 p 值不可输入。
  • 极端稀有事件（n<100 的阴性对照） —— 校准 CI 极宽，结果不可靠；应优先报告方向而非具体概率。
  • 治疗领域/人群与本模拟研究（β 受体阻滞剂、MIMIC-IV）差异巨大 —— 阈值 0.15/0.45/0.65 是经验值，跨场景迁移需要重新做一组 64 万次模拟。

§8 常见问题

  1. Q：算法需要我提供"窄"还是"宽"吗？
    A：不需要。你只填入 BF̂ 区间即可。算法内部自动识别区间宽度并取保守值。你唯一需要做的，是如实报告论文里的 CI。
  2. Q：BF̂ = 0 怎么处理？
    A：BF̂ = 0 意味着校准后几乎看不到经验偏倚。如果同时校准 p < 0.05，算法进入第二层；BF̂ = 0 通常对应"可作效应证据"（除非 CI 宽得离谱，但区间会触底于 0，半宽通常很小）。
  3. Q：BF̂ = 1 怎么处理？
    A：BF̂ = 1 意味着整个效应都被系统偏倚解释。如果 p_cal < 0.05（信号居然显著）但 BF̂ = 1，几乎肯定是"假信号"——算法的"不可作效应证据"档正是为这种情况设计的。
  4. Q：为什么"势均力敌"是一个独立档？为什么不归到"不可作"？
    A：因为 BF 居中、CI 偏宽时，我们不知道是真信号还是偏倚主导。把它判为"不可作"会丢掉可能的真效应；判为"可作"又会引入假阳性。势均力敌档说"待证据累积"——不是放弃判断，是给一个更细的处理路径（参见 v38draft §9 混合区处理清单）。
  5. Q：如果论文报告的是 BF（不报告 CI）怎么办？
    A：算法需要 BF 的 CI 才能定位 12 段读数桶。缺 CI 不要硬猜，请直接向作者索要 Bootstrap CI 后再判。
  6. Q：算法输出"P(偏倚主导) ≈ 3.1%"，但这一位数是不是太粗？
    A：保留 1 位小数是设计选择。刻意粗一些是因为概率本身来自 64 万次模拟的经验分布，单数点估计的尾位数字不应过度解读。如有需要可在内部查 D.relia 数据拿更高精度，但给临床的输出就到这里为止。
  7. Q：软件报给我的 95% CI，到底是「窄档」还是「宽档」？
    A：只有一个 CI，它本质既不是窄也不是宽。软件从你的 μ̂_B 经 Bootstrap 得到唯一一条 95% CI（如 [0.10, 0.45]），用单调变换 g 映射成 BF 的 CI，这就是你看到的全部。所谓「窄/宽」只是算法拿这条 CI 的半宽（如 (0.45−0.10)/2 = 0.175）去跟固定阈值 0.133 比一比、贴的内部标签，用来决定去查哪一张预计算表。
    两张表（D.reliaSplit.narrow / .wide）是 64 万次模拟离线一次性算好的条件概率（「在 CI 窄的前提下真偏倚主导的比例」与「在 CI 宽的前提下」的比例），不是你这次运行时生成的，也不是两条不同的 CI。算法读完两列后取 max(窄, 宽) 作保守判读，所以你最终看到的那个 P 值已经是两档里的「更坏情形」。正因如此你完全不需要知道本次被归到窄还是宽，这也是当初把它从临床界面隐掉的原因。

§9 为什么「校准 p + BF」比单独看 p 更强（写给持怀疑态度的读者）

不少临床同事的直觉是：校准 p < 0.05 已经说明「治疗有效」，BF̂ 与它的 CI 只是把「约 1/3 是偏倚」换种说法重述一遍，和看 logistic 回归的 RR + 95% CI + p 没什么两样。下面说明这种直觉对了一半、错在致命的一半。

对的部分：BF̂ = 0.33 确实就是在说「估计约 1/3 的表观效应来自系统性偏倚」，这点手算也能得到。
错的部分：「校准 p < 0.05 = 治疗有效」在观察性研究里是根本性统计谬误。p 值只排除偶然（随机噪声），排除不了混杂。校准 p 比朴素 p 强（它用阴性对照做了经验校准，去掉了这项研究本身的系统性 p 膨胀），但仍只回答「有没有区别于零的信号」，不回答「信号是真的还是偏倚造成的」。后者正是 BF 这一层在干的事。logistic 的 RR + CI + p 只回答「有无关联、关联多大」，对「关联里多少是偏倚」结构性沉默。

9.1 最有力的对照反例：两个「校准 p 完全相同」的研究

9.2 关于「P(偏倚主导) ≈ 26.5% 没增加信息」

你手算的「1/3」是 BF̂ 的点估计（本研究偏倚份额的分解）；而 26.5% 是模拟校准后的「真实处于偏倚主导体制的概率」，并且因为你的 CI 偏宽被上调了（同一读数桶：窄档仅 8.8%、宽档 26.5%）。这是两个不同的问题：

  • BF̂ = 0.33 → 「这个研究的效应里，估计 1/3 是偏倚」（分解）
  • P(偏倚主导) ≈ 26.5% → 「考虑到你的 CI 很宽，模拟里同类研究真正落在偏倚主导体制的概率是 26.5%」（体制归类 + 宽度修正）

朴素 RR + CI + p 既给不出 26.5% 这个数，也给不出「混合」这个决策档。框架在中段 BF 的增量，是用 CI 宽度修正了你偏乐观的点估计，并给出体制归类。

9.3 诚实的局限（先承认，才说得服人）

本框架的威力是不对称的：在两端（红 / 绿）它很强，能拦住假性效应、也能背书真效应；在中段 BF 它本就是「诚实的不确定」。对研究 1 这种中等 BF，框架确实不「拍板」，它的价值恰恰是拒绝让你仅凭 p < 0.05 就宣布有效，逼你走「生成假设、累积更多证据」这条路。所以临床同事觉得「好像没增加判断」，往往正是因为数据本来就不该让你下结论，框架只是诚实地说了出来。
