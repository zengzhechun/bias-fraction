两个衔接命题

衔接 A（第一部分到第二部分）：BF 的分子 |μ̂B| 与分母中的 ψ̃ 都是估计量，因此 BF 本身带估计误差。真实数据里 BF 的真值永远不可知，无法自证准确性。要检验这个量，必须构造一个真值已知的世界，这就是模拟研究存在的唯一理由。

衔接 B（第二部分内部，第 1 步到第 2 步）：Bland-Altman 只能回答一致性，也就是 BF̂ 是否接近 BFtrue。但一致性不等于决策有用。一个偏低 0.05 的量仍可能把偏倚主导的估计判成可用。所以第 1 步之后必须紧接第 2 步，把评价标准从「测量误差」换成「决策错误率」。

衔接 C（第二部分到第三部分）：模拟里的判读规则是在已知真值下校准出来的，因此可以携带到真实数据中使用。第三部分不再验证方法，而是应用这套已经校准好的读数规则，去看一个方法学上尽可能严格的 TTE 还剩下多少系统误差。

第一部分 · 指标Part I. The metric

1.1 负对照与经验零分布 Negative controls and the empirical null

负对照结局（negative control outcome）是那些在生物学上不可能被暴露影响的结局。对同一套数据、同一套调整策略、同一个估计量，把 K 个负对照各跑一遍，理论上应该得到 K 个零效应。实际得到的是一团偏离零的估计，这团估计的分布就是经验零分布（empirical null）。

ln RRk ~ Normal(μB, σB2 + sk2), k = 1, …, K # μ_B 是系统偏倚的中心，σ_B 是负对照之间偏倚的异质性，s_k 是第 k 个负对照自身的抽样标准误

OHDSI 的 EmpiricalCalibration 框架用这个分布做两件事：把目标估计的 P 值校准成校准 P 值（calibrated p-value），把点估计校准成校准效应。它给出的是一个二分答案，信号在扣除系统偏倚后还站不站得住。它不回答一个连续的问题：这个信号里有多大比例本来就是偏倚。

图 1. 第三部分实际使用的 12 个负对照的经验零分布。全部 12 个都落在保护侧，说明偏倚有方向而非随机噪声。μ̂B 与 σ̂B 由极大似然联合估计，Shapiro-Wilk 检验用于核查正态假设。

1.2 BF 的定义 Defining the Bias Fraction

把估计出来的系统偏倚中心 |μ̂B| 与校准后剩下的效应量 ψ̃ 放在同一把尺子上比，得到偏倚在观测关联中所占的份额。

BF = |μ̂B| / ( |μ̂B| + |ψ̃| ) ∈ [0, 1] # ψ̃ = 校准后的 ln RR，也就是扣掉系统偏倚之后剩下的效应估计 # BF → 0：观测关联几乎全部是效应 # BF → 1：观测关联几乎全部是偏倚

三条性质使它可以当作可信度刻度使用。第一，它无量纲，跨结局跨数据源可比。第二，它有自然的两个端点，不需要人为设定量纲。第三，它把「偏倚存在」与「偏倚多大」分开，前者由校准 P 值回答，后者由 BF 回答。真值分区按 BFtrue 定义：大于 为偏倚主导，小于 为效应主导，其间为混合。

计算器：拖动两个输入，看 BF 与分区如何变化

灰色刻度条是 BF 的 0 到 1 全域，竖线是当前 BF。两条虚线是真值分区的两个阈值。注意 BF 对分母的敏感性：当 ψ̃ 趋近 0 时，BF 无论偏倚多小都会趋近 1，这是分数型指标的固有性质，也是第二部分必须把 ψ = −0.01 这一近边界水平单独处理的原因。

1.3 区间的构造与覆盖 Interval construction and coverage

BF 是两个估计量的比值函数，直接用 delta 法在 ψ̃ 接近 0 时会失效。第38版采用两条路径并比较：一条是对 (μ̂B, ψ̃) 的联合后验做 MCMC 抽样再传播到 BF，另一条是纯 Monte Carlo 传播。前者为主分析。

图 2. 95% 区间的覆盖率随 BF 真值十分位的变化，按区间宽度分层。整体覆盖低于名义 95%，且窄区间的覆盖明显低于宽区间。这一点在论文里必须如实披露：BF 的区间是保守程度不足的，因此第二部分的判读规则不能直接用区间覆盖来背书，而要用已知真值重新校准一次。

一、五个因子的取值水平为何如此设定

1. 真效应 ψ（ln RR），10 档（−0.40 到 −0.01，步长约 0.043）。在 ln(RR) 尺度上等距取 10 档，覆盖从中等强度效应（RR≈0.67，ψ=−0.40）到近零效应（RR≈0.99，ψ=−0.01）的完整区间。取负号源于 β 受体阻滞剂在心衰队列中表现为风险降低、ln(RR)<0。采用 ln(RR) 而非 RR 尺度，是因为经验零分布与 BF 的全部推导都建立在正态的对数相对风险尺度上，效应与偏倚可在同一尺度直接相减。最右端的 −0.01 是刻意保留的近边界点：当 |ψ̃|→0 时 BF 分母趋零、BF 不论偏倚大小都逼向 1，这是分数型指标固有的数值脆弱区，也是决策最敏感、必须单独处理的角落，讲解器因此将其单列并排除出内点一致性分析。10 档的密度足以充分取样 (ψ, μ_B) 平面，同时把总分析量控制在 96 万次的可行范围。

2. 偏倚中心 μ_B（ln RR），8 档（−0.40 到 −0.05，步长 0.05）。这是负对照经验零分布的均值，即系统性偏倚的大小。与 ψ 采用相同负向跨度、但末档止于 −0.05（而非 −0.01），因为零分布中心通常比主效应更靠近零。8 档与 10 档 ψ 交叉构成 80 个 (ψ, μ_B) 单元，能够覆盖 BF 的全部三个真值分区（|μ_B|≫|ψ| 时 BF→1，偏倚主导；|μ_B|≪|ψ| 时 BF→0，效应主导；中间过渡带为混合），这个二维扫描是检验 BF 区分力的核心。

3. 观测精度 σ_PS（即 se_psi_obs），2 档（0.06 与 0.10）。先澄清一处实现细节：在本版代码中，这个因子传入的是目标效应估计 ψ̂ 的观测标准误，而不是原表注所写的「负对照之间偏倚的离散程度」。负对照之间的异质性由固定参数 bias_sigma = 0.05 控制，并不作为扫描因子。该因子取「较精确」臂（SE = 0.06）与「较不精确」臂（SE = 0.10）两档，大致包住 MIMIC 队列在所选样本量下 Cox 模型 ln(RR) 估计的典型标准误。它是 BF 不确定区间宽度的最主要驱动者：SE 越大，ψ̃ 的置信区间越宽，越易落入混合或无法判定区，因此通过操控观测精度来检验 BF 区间在信息量强弱两种情形下的表现。

4. 负对照个数 K，3 档（12、25 与 50）。K 是经验零分布所依赖的负对照数量，直接决定 μ_B 与 σ_B 估计的信息量，进而决定 BF 区间宽度与校准 P 值的离散度。取 12、25 与 50 对应「负对照池较薄」「适中」与「较厚」三种现实场景。OHDSI 经验校准实践中可用负对照通常在十几到几十个之间；12 是偏保守的下界（许多真实分析负对照集并不充裕），25 接近文献中较理想的规模，50 则代表负对照充裕的乐观场景。三档并列能直接展示「负对照越多、BF 判定越稳」这一核心结论，也为方法对负对照稀缺性的稳健性提供边界证据。

5. 可交换性违背程度，2 档（0 与 0.3）。这是本方法最关键的假设敏感性维度。0 表示负对照与目标暴露的偏倚完全可交换（核心假设成立）；0.3 表示 30% 的负对照携带与主效应同向、大小为 μ_B + 0.15 的额外偏倚，即核心假设部分失效。取这两个极端是为了最大化区分「假设成立」与「假设明显违背」下的误判结构差异，从而量化方法对可交换性违背的脆弱程度。模拟显示 30% 违背会使误用率明显抬升，因此这一项必须是局限讨论的第一条。

二、960 条件 × 1000 次重复的随机性与变异性从何而来

每个条件（一个固定的 (ψ, μ_B, σ_PS, K, exV) 组合）独立重复 1000 次。每次重复走完全相同的数据生成与估计流程，但每次都重新从随机分布抽取新样本，因此 1000 次之间产生变异性。具体而言，在 run_method_compare 的每次重复 r 中，以下量被重新随机生成：K 个负对照的效应估计 Y_k ~ Normal(μ_B, 0.05²)（k = 1,…,K，负对照间异质性固定为 0.05；其中 30% 违背组额外叠加 +0.15 的系统偏倚）；每个负对照的估计标准误 s_k ~ Uniform(0.03, 0.12)；目标效应的观测值 ψ̂ = ψ_true + μ_B + Normal(0, σ_PS²)（σ_PS 即 0.06 或 0.10）。随后对每次重复同时运行两套估计：MC 路径用 fitNull（最大似然、无先验）得 μ̂_B 点估计与 Bootstrap 区间；MCMC 路径用自定义 Gibbs 采样器 mcmc_fit_null 得 μ_B 后验并传播到 BF。

随机种子方面，run_method_compare 在进入 1000 次循环前执行一次 set.seed(seed)（seed = 全局 43 + combo_idx×100），循环内所有 rnorm、runif 调用共享同一条但连续推进的随机流；每次重复的 MCMC 链再以 seed + r 单独播种（r = 1…1000）。这样同一条件内的 1000 次重复相互独立、跨条件互不串扰，96 万次分析构成一组可复现的蒙特卡洛实验。

三、Gibbs 采样过程中究竟从什么分布抽样（分布类型与参数）

本版 MCMC 并非 EmpiricalCalibration 包的 Metropolis-Hastings 函数，而是 R/02 自定义的 Gibbs 采样器 mcmc_fit_null。模型为：对 K 个负对照估计 Y_k ~ Normal(μ_B, σ_B² + s_k²) 做贝叶斯估计，关注参数为 (μ_B, σ_B²)，s_k 为已知标准误。先验取弱信息：μ_B ~ Normal(0, 1)（均值先验，方差 1）；σ_B² ~ Inverse-Gamma(0.5, 0.05)（形状 0.5、尺度 0.05）。后验的两个满条件分布均闭合可解（共轭），因此逐参数轮换抽取：

（a）μ_B | σ_B², 数据：Normal 后验，均值 = (μ_0/τ_0² + Σ Y_k/v_k) / (1/τ_0² + Σ 1/v_k)，方差 = 1/(1/τ_0² + Σ 1/v_k)，其中 v_k = σ_B² + s_k²、τ_0² = 1 为先验方差；从 rnorm(1, mean_post, sqrt(1/prec_post)) 抽取。
（b）σ_B² | μ_B, 数据：Inverse-Gamma 后验，shape = 0.5 + K/2，rate = 0.05 + 0.5·Σ[(Y_k − μ_B)² + s_k²]；从 1/rgamma(1, shape = shape_post, rate = scale_post) 抽取。

迭代设置：本版模拟调用时取 mcmc_iter = 400、mcmc_warmup = 100（保留后 300 个抽样），每条链以 seed + r 独立播种。得到 (μ_B, σ_B²) 抽样后，用 ψ̂ − μ_B 传播到 BF，取后验中位数作点估计、2.5% 与 97.5% 分位数作 95% 可信区间。它与 MC 路径的区别在于：MC 用 fitNull 的最大似然点估计加 Bootstrap 传播区间，MCMC 则用上述 Gibbs 后验直接给出 μ_B 的不确定性；二者在模拟中并列比较，MCMC 路径被定为主分析。

四、这个设计空间有代表性吗？够不够宽？（审稿人与同事最常问的两问）

1. 先澄清一件事：960 个条件不是「抽样」，而是刻意构造的正交设计网格。模拟研究的目的，是在受控条件下比较方法的相对性能排序，而不是预测绝对性能，更不是对现实研究做代表性抽样。稿件 eMethods 开宗明义地否定了「代表性」这一目标：因子水平「并非为了代表心血管观察性研究的一项调查而选取」。因此，问「这个空间有没有代表性」这个框架本身就不适用——它从未打算复刻现实的分布，而是要把方法性能可能发生反转的区域系统地走一遍。这也是为什么五因子要完全交叉、不留空档：960 个条件是 10×8×2×3×2 的全组合，每一个格子都被走到。

2. 每个水平都有锚定依据，不是拍脑袋定的。eMethods 给了一张逐因子的论证表：真效应 ψ 的 10 档覆盖 RR 0.67–0.99，并包含本研究 β 受体阻滞剂的实测值（ln RR ≈ −0.18）；偏倚中心 μ_B 的 8 档逼近 Simpson 2006 报告的健康依从者效应（OR 0.56，ln −0.58），并包含本研究负对照面板拟合出的 μ̂_B（−0.190）；观测精度 σ_ψ 的两档包住两个临床问题估计量的实测标准误；负对照个数 K 的 12 取自 MIMIC-IV 实际可得的心血管面板，25 与 50 用来检验性能是否见顶；可交换性违背则明确标注为设计选择——0 对应假设成立，0.3 是故意打破假设的扰动，不对应任何经验估计。换句话说，网格的边界是由真实数据撑开的，不是由便利决定的。

3. 设计本身符合公认规范。全因子完全交叉、无缺失组合；每个条件 1000 次重复，处于模拟研究推荐的 1000–10000 区间；关键因子（ψ 十档、μ_B 八档、K 三档）水平数均不少于 3，足以捕捉非线性；全流程遵循 ADEMP 框架（Morris 等，2019）。由于总重复数达 96 万，任何报告比例的蒙特卡洛标准误都低于 0.07 个百分点——这是模拟研究最硬的一项指标，也是「重复次数够不够」这一问的正面回答。

4. 稿件主动承认了三处「不够宽」，而这三处的方向性才是关键。eMethods 列出了网格未能包住本研究案例的三点：其一，负对照间标准差被固定为 0.05，低于案例面板拟合出的 0.068；其二，负对照标准误取自 0.03–0.12 的均匀分布，而实测范围是 0.025–0.302，且有 3 个对照超过 0.24；其三，GDMT 的估计值（ln RR −0.38）落在网格相邻两档之间，仍位于 ψ 网格之内（该网格最极端的一档为 −0.40）。稿件随即点明，这三处全部使模拟条件比真实案例更宽松、更有利于估计量。

5. 这意味着仿真给出的不是乐观外推，而是乐观下界。既然模拟运行的条件比本研究真实面对的情形更宽容，模拟得出的结论就构成一个下界：如果 BF 在比现实更有利的条件下仍然暴露出局限，那么真实世界只会更严峻，不会更好。这是一个方向明确的保守论证——它没有声称「现实就是这样」，而是声称「现实至少不会比这更好」。把这一层意思讲清楚，比再补一个更大的网格更有说服力，因为它锁定了结论的方向，而不只是扩大了结论的范围。

一句话回应口径：「这个网格不是对现实研究的抽样，而是锚定本研究实测值与已发表文献构造的受控设计空间，遵循 ADEMP 框架，每个水平的依据列在 eMethods 的论证表中。稿件已主动列出三处网格未能包住案例之处，且这三处全部让模拟条件比真实案例更宽松，因此模拟结果是乐观下界：在比现实更有利的条件下我们仍观察到 BF 的局限，现实只会更严重。这是保守结论，不是乐观外推。」

2.2 第一步：Bland-Altman 一致性 Step 1. Bland-Altman agreement

衔接 B · 从测量误差到决策错误

第 1 步的结论是 BF̂ 系统性偏低而且偏低幅度随真值增大。如果直接拿 BF̂ 和 0.5 比较，偏倚主导的估计会被系统性地判轻，这是最危险的一类错误。因此第 2 步不再问 BF̂ 离真值多远，而问：把 BF̂ 连同它的区间放进一个用真值校准过的判读规则后，误判率降到多少。测量的缺陷可以由校准后的判读规则吸收，这是第 2 步的核心论点。

2.2b 深度问答 · 系统性低估：缺陷还是固有收缩 Why BF̂ underestimates: design flaw or intrinsic shrinkage

把 2.2 的「方向性低估」拆开讲透：是缺陷还是固有性质、审稿人质疑怎么回应、能否加修正项、能否用仿真斜率做线性校正。回归口径与 2.2 一致（差值对 BFtrue 回归）。

Q1 · 设计缺陷，还是固有性质？

固有收缩（shrinkage），不是 BF 定义本身的缺陷。三个证据链：

① 机理可推。BF̂ 的两个输入都带噪声（μ̂B 带 σB/√K 级拟合误差，Y 带抽样误差 s）。噪声经 BF 这个非线性映射后有两组 Jensen 效应：E[|μ̂B|] ≥ |μB| 推高 BF̂，E[|ψ̂|] ≥ |ψ| 推低 BF̂，两力部分抵消；更主导的是 BF ∈ [0,1] 有界，噪声把极端值往中心压。

② 回归签名是收缩不是单向偏差。intercept +0.029、slope −0.181 的组合，换算成 BF̂ 对 BFtrue 的回归是 BF̂ ≈ 0.029 + 0.819 · BFtrue。intercept > 0 且斜率 < 1，即「低端抬高、高端压低、向中心收」，是向均值回归的教科书签名。若真是公式设计造成的系统性低估，intercept 应 ≤ 0 且各区间一致低估。

③ 内点数据把责任指给边界条件。排除 ψ = −0.01 后 slope 从 −0.181 缩到 −0.059（λ≈0.94，收缩仅 6%），约三分之二的比例偏差来自 ψ = −0.01 这一极端设计层。严重程度：绝对数值层中等（平均低估 0.069、CCC 0.781、93.8% 在 LoA 内），决策层已被校准机制吸收（AUC 0.951 / 0.918，R4 实测误放率 2.9%）。

Q2 · 审稿人质疑时怎么回应

1 区分估计量噪声与指标定义。slope < 1 是有界统计量加输入噪声的必然结果，与 Bland-Altman 方法学中 proportional bias 的解释框架一致；真值层面 BF 定义没有任何单调性或对称性缺陷。

2 稿件已主动披露并转化为设计动机。正文那句「motivating truth calibration」正是关键，R4 的 verdict 查找表就是 E[truth | BF̂] 的校准实现。我们没有掩盖低估，而是把它作为引入校准层的实证依据。

3 判别力不受影响。收缩单调、不改变排序，AUC 完整保留。

4 失效方向保守。低估 BF̂ 使判定更倾向 withhold（宁可错杀），对可信度指标是安全方向。

5 K 梯度给出可量化改进路径。K = 12 / 25 / 50 的半宽 0.193 → 0.121 → 0.081。

6 类比先例。回归稀释（Carroll）、心理测量衰减（Spearman）、GENG 校准覆盖不完美，同构。

Q3 · 计算中加修正项可行吗

路线 A（推荐，已实质存在）：校准「决策」而非「点估计」，即 verdict 查找表，输出 P(BD | BF̂) 而非校正后的 BF。最稳健，不依赖逆变换的数值稳定性。

路线 B：方差感知的解析校正，delta method 抵消 Jensen 项。风险：BF 近 0 / 1 时一阶展开失效、边界需截断、每次要估计噪声方差。

路线 C：全局线性校正，见 Q4。共同风险：① 双重校正（查找表、桶边界、阈值全基于未校正 BF̂ 构建）；② 网格外推（新研究 K / σB / s 不匹配时反向过校）；③ 可解释性损耗（校正后 0.5 不再对应「势均力敌」的直觉语义）。

Q4 · 用仿真斜率做线性校正

形式：BFcorr = (BF̂ − 0.029) / 0.819，截断到 [0,1]。

不变性：任何正斜率单调变换不改变排序，故校正后 AUC、Youden 排名、ROC 形状完全不变；校正的全部价值只在「绝对数值语义」层。代价是 R2–R4 的 0.5、1/3 阈值必须在新尺度重平移，否则判定集合改变、全部下游结果重跑。

适用条件：新研究的 K、阴性对照质量、σB 与仿真网格匹配，且真实 BF 分布与仿真先验相近。这是硬限制（与 0.30 切点、查找表同为网格特异）。

包集成：函数简单、工程在护栏。建议 opt-in；主输出保持原始 BF̂ + verdict（校正值仅附加列，杜绝双重校正）；显式截断并报告比例；校正参数随网格 fingerprint 版本化；单元测试断言「校正不改变 verdict」。

综合建议：不把线性校正写进主方法。最佳位置是补充材料的敏感性分析：展示「校正后 slope → 1、CCC 改善、AUC 不变（单调性保证）」，一次性把审稿人的质疑转成支持性证据。

给临床大夫的提示 ·「桶」是什么，0.1299 又是谁的中位数。

"桶"是英文 bucket 的直译，指本研究把 BF̂ 这个连续数值"分装进格子"的做法。模拟里每一次分析都会算出一个 BF̂（取值在 0 到 1 之间）。如果对着每一个具体的 BF̂ 值去问"它真实偏倚主导的概率是多少"，单次样本太少、估计不稳。所以研究把所有 96 万次模拟的 BF̂ 按大小排序，切成 12 个"等频桶"，也就是每个桶里大约装着同样多的模拟结果（等频指每桶数量相等，而不是每桶 BF̂ 宽度相等）。接着对每个桶，数一数里面真实是偏倚主导的分析占多少比例，得到"该桶内偏倚主导概率"。12 个桶的概率排成一张表，就是表 2 的"十二桶查照表"。决策台里"BF̂ 落进第几桶"查的正是这张表。它之所以站得住脚，是因为图 6 显示桶中心 BF̂ 越大、桶内偏倚主导比例也越高（单调上升），证明 BF̂ 的大小确实对应可信度高低，把它当作连续可信度量是成立的。

按区间半宽是否超过中位数 分类中的"中位数"，是指96 万次模拟中所有 BF̂ 95% 区间半宽的全体分布的中位数。计算口径是同一组合下 1000 次重复各自的 (BF_hi − BF_lo) / 2 取中位，再在 960 个条件之间汇集：25%/50%/75% 分位是 [0.0876, 0.1299, 0.1913]。换句话说，"半宽不超过 0.1299 归为窄"的意思是：在这次模拟的总体噪声水平里，约一半的 BF̂ 区间被估得比典型值更窄，另一半比典型值更宽。窄区间对应的 BF̂ 点估计更可信，因此在与查照表配合判读时给予保留；宽区间判读则取保守值，避免把不确定当作确定。注意这里切的是"区间宽窄"，与上一节按 BF̂ 大小切的"桶"是两套不同的分法。

这个分类不是任何外部黄金标准，而是一种自适应阈值：用本研究自身的噪声分布来切两档。这样做的好处是当样本量变大、负对照增多、模型变好时，判读严格度自动随总体精度一起抬高，不依赖人工调参。

为什么把这一节放在第三部分，而不是直接摆数据 Why Part III exists before the case

真实世界证据越来越进入指南与监管决策。研究者用目标试验模拟（target trial emulation, TTE）、TMLE 等方法在观察数据上尽量模仿随机试验的设计。但这些方法共同依赖一个关键假设：无未测量混杂（no unmeasured confounding），即"所有影响治疗与结局的共同原因都已被测量并调整"。该假设不可证伪，因此任何严肃的 TTE 报告都必须配一个"经验性的偏倚检查"。

一项调查数据。Ren et al.（JAMA Network Open 2026）对 237 项 TTE 研究的横断面调查发现，只有 30.8% 的研究用统计方法评估了未测量混杂。也就是说，近七成的 TTE 研究没有做任何经验性的偏倚检查，就直接报告了因果结论。本部分第三部分要做的，就是给 β 受体阻滞剂与 GDMT 这两项 TTE 配备这一关：本研究已经在 960 条件 × 1000 次模拟下校准出 BF 与查照表，正好可以在真实数据上复现这一关。

健康依从者效应：药物流行病学里最顽固的混杂 The healthy adherer effect

健康依从者效应（healthy adherer effect, HCE）：能够耐受并坚持用药的患者，即便服的是安慰剂，结局也更好，因为他们本身更健康、更自律、医疗可及性更高。在观察性研究中，"依从治疗 / 达标剂量"这件事本身就携带大量与药物无关的预后信息。β 受体阻滞剂研究的经典 RCT 用严格的入组和依从监测把这种混杂压低到可忽略；在 MIMIC-IV 这类电子病历数据上，则必须靠负对照与 BF 来把它揭穿并量化。

前置工具：校准 P 值是怎么从 K 个负对照算出来的 The calibrated p-value, in three steps

在讲具体案例之前，先用临床的语言把"已有的校准方法"（OHDSI 经验校准框架，Schuemie et al. 2014/2018，R 包 EmpiricalCalibration）拆成三步。它建立了三个依次递进的概念：负对照 → 经验零分布 (μ̂B, σ̂B) → 校准 P 值。本论文的 BF 与 BER 正是踩在这套肩膀上。

第一步 · 什么是负对照结局
负对照是一个治疗不可能影响的结局，但它与主结局共享同一套混杂结构（同一批未测量的因素 U 同时污染它与主结局）。因为真实效应已知为零，所以一旦观察出"治疗与负对照相关"，这段相关只能来自偏倚。例如：β 受体阻滞剂不可能预防白内障，但 MIMIC-IV 中达标组的白内障发生率也是 3.2% vs 4.2%，RR≈0.76。这 0.76 的"保护"只能来自 HCE 这类混杂，正是我们要校准的偏倚的直接证据。
第二步 · 估计系统偏倚的分布 (μ̂B, σ̂B)
把 K 个负对照各自的 (ln RR, se) 估计交给软件包，按 (μ̂B, σ̂B) 拟合出一条经验零分布钟形。钟心 μ̂B 表示设计平均把治疗效应估计值往哪边偏了多少；宽度 σ̂B 表示不同负对照之间偏倚的离散程度。本研究 β 受体阻滞剂部分选用 12 个负对照，全部偏向保护一侧，拟合出 μ̂B = -0.190（ln RR 尺度，平均把治疗效应往"保护"方向推 0.19），σ̂B = 0.068（各对照间偏倚相当一致）。
第三步 · 把治疗估计值放进偏倚钟形里重新检验
校准 P 值回答的是："以第二步由 K 个负对照拟合的偏倚钟形（以 μ̂B 为中心，并纳入 σ̂B 的不确定性）为参照，治疗效应估计值是否仍然显著不等于零"。本研究 β 受体阻滞剂案例：未校准 ln(RR) = -0.184（即 RR ≈ 0.83，表观 17% 的死亡降低）。放进以 -0.190 为中心的偏倚钟形里，该估计落在正中央，说明"差异"几乎就是未测量偏倚本身。于是校准 P = 0.94：扣除偏倚后没有证据显示真实效应存在。这是校准 P 值 / 第 1 层判据的典型用法。

偏倚交换性：为什么负对照能校准主结局 Bias exchangeability: why negative controls can calibrate the primary outcome

严谨定义：在给定已测协变量后，影响主估计的残留偏倚的分布，约等于支配负对照估计的偏倚分布。这是整个方法成立的关键假设，与它所诊断的“无未测量混杂”一样，无法用数据直接验证。

左：交换性成立。已测混杂 X（蓝色实线，临床可拿到并写入 PS / 匹配 / 分层 / 回归的协变量）被条件掉以后，剩下的未测量混杂 U（红色虚线）仍是 N 与 Y 共用的同一把尺子，校准有效。右：交换性被破坏。X 同样被条件掉（蓝色实线存在），但未测量部分拆成 U₁（只染 N）和 U₂（只染 Y），两把尺子不同，用 N 校准 Y 会用错尺子，校准 P 与 BF 失真。

第三部分 · β 受体阻滞剂目标试验模拟Part III. The beta-blocker target trial emulation

3.1 设计 Design

数据来自 MIMIC-IV 与 MIMIC-IV-ECG。设计上尽可能贴近目标试验：明确的合格标准、明确的零时点、明确的治疗策略、意向治疗与按方案两套分析、用 LTMLE 处理时变混杂与删失。这已经是观察性数据上能做到的最严格设计之一。

两个临床问题的设置是刻意对照的：

问题一 · 单药达到 50% 目标剂量与一年死亡率
这是文献中反复出现的「达标剂量有保护作用」类命题，也是最容易被健康使用者偏倚污染的命题。能耐受达标剂量的人，本身就更健康。
问题二 · GDMT 多药联用达到 2 类及以上与一年死亡率
指南导向药物治疗的联合效应有随机对照试验支撑，因此作为一个更接近阳性对照的问题。如果方法把它也全盘否掉，说明规则过于严苛。

先厘清两个关键概念

①「达到 ≥50% 目标剂量 β 受体阻滞剂」与「<50%」分别指什么？心衰指南要求 β 阻滞剂从极小剂量起步、逐步向上滴定到「目标剂量」（例如比索洛尔 10 mg/天、卡维地洛 25 mg 每日两次、琥珀酸美托洛尔 200 mg/天）。本研究不比较「有没有开这个药」，而是比较「出院时实际被滴定到了多少」：达到至少一半目标剂量的患者，与低于一半（<50%）的患者，并假定他们在出院后一年内维持出院时的用量，比较两者一年后的心血管事件发生率。这正是最容易混进健康依从者效应的地方：能顺利爬到目标剂量的，往往是更耐受、更自律、被更积极随访管理的人，他们本来预后就更好。

②「GDMT 治疗」是什么？为什么只算 3 类药、不是临床医生印象里的 4 类？GDMT（指南导向药物治疗）是射血分数下降型心衰（HFrEF）的标准治疗。临床医生如今熟悉的「四根支柱」是：肾素-血管紧张素系统阻断剂（ACEI/ARB/ARNI）+ β 阻滞剂 + 盐皮质激素受体拮抗剂（MRA，如螺内酯）+ SGLT2 抑制剂（如达格列净）。但本研究只取前 3 类（ACEI/ARB/ARNI + β 阻滞剂 + MRA），不把 SGLT2 抑制剂算进去。原因是 SGLT2 抑制剂用于心衰是 2020 到 2021 年才写进指南（达格列净的 EMPEROR-Reduced、恩格列净的 EMPULSE 研究），而 MIMIC-IV 这批患者的住院时间大多在这之前，队列里几乎没人用过 SGLT2 抑制剂。如果硬要「集齐 4 个药才算 GDMT」，我们的阳性对照人群会几乎为空、毫无区分度。所以本研究把 GDMT 锚定在当时真正的标准治疗上：3 类药物。这样 GDMT 才是一个「确实被广泛使用、且真实效应很大」的阳性对照，用来检验校准方法会不会矫枉过正（把真效应也一起扣掉）。

为什么做这项案例研究，先说临床问题本身

β 受体阻滞剂是射血分数降低型心衰治疗的基石：随机试验（MERIT-HF、CIBIS-II、COPERNICUS）证明目标剂量能降低死亡。但真实世界里，能达到目标剂量的患者不到一半。于是每个心内科医生都见过这样的数据：「剂量达标的患者，死亡率更低」。观察性研究一再重复这个保护性关联，临床上的直接推论就是「应该更积极地向上滴定」。可问题在于：这是药的作用，还是人的作用？能被滴定到目标剂量的患者，本来就是血流动力学更稳、肾功能更好、依从性更高的患者（即前文的「健康依从者效应」）。这个问题无法用随机试验回答：伦理上不允许把患者随机分配到「不滴定」组，所以只能靠观察性数据，而观察性数据又天然被这个问题困扰。它是「表面关联与真实效应难以区分」的最典型场景，也是示范一个偏倚诊断指标的最佳考题。

为什么选 MIMIC-IV 这个数据库

三个理由。① 真实的混杂结构：这是真实 ICU 的真实临床数据，混杂以它真实的样子存在，而不是教科书里的玩具数据；指标若在这里失灵，就是真的失灵。② 出院后死亡随访完整：MIMIC-IV 的死亡记录延伸到出院之后，「1 年全因死亡」这一硬终点才有完整随访（许多数据库做不到，只能用住院死亡等软性替代）。③ 完全公开、可复现：任何人都能下载数据、重跑整个分析，这是方法学示范的必要条件；配套的 ECG 数据还提供了 QRS、QTc 等生理协变量。最终队列：14,677 例心衰住院患者。

为什么这样设计，每一项决定都在防一个具体的偏倚

一个「看起来很简单」的两组比较（剂量达标 vs 未达标），背后是一连串刻意的设计决定。理解它们各自在防什么，才能理解为什么这项研究敢自称「严谨」，也才能理解后面「即便如此仍有偏倚」的结论有多大的冲击力。

3.1.1 为什么用 TMLE + SuperLearner Why TMLE + SuperLearner

本研究在分析层采用 TMLE（targeted maximum likelihood estimation，靶向最大似然估计）配合 SuperLearner 集成学习。这不是随意选择，而是为了让规范设计（TARGET）与前沿估计各司其职、互相补位。

① TMLE 的双重稳健性（doubly robust）。TMLE 同时拟合倾向模型与结果模型，并把两者结合起来。它的关键性质是：只要两者之一设定正确，因果估计就一致。相比之下，传统回归调整要求结果模型完全正确、IPTW（逆概率加权）要求倾向模型完全正确，任一误设即偏。TMLE 还是半参数有效的，在同类估计器中方差最小。因此即便真实关系复杂，TMLE 也不像单一模型那样脆弱。

② SuperLearner 是 TMLE 的配置层（nuisance 引擎）。TMLE 的质量取决于那两个 nuisance 函数的拟合。SuperLearner 不赌单一参数形式，而是用交叉验证从一组候选算法（glm、gam、xgboost 等）中按样本外风险选出最优加权集成。即使真实关系高度非线性，集成也能自适应捕捉，渐近上它不劣于（且通常优于）任一单个候选。本研究测试了三套库（SL.glm / +SL.gam / +SL.xgboost），结论稳健（见 3.4 敏感性分析）。

TMLE 数学原理 · 核心公式 TMLE mathematical principle · core equations

下面给出 TMLE 在本研究 RR 尺度上的关键公式。符号约定：$O = (W, A, Y)$，$W$ 是协变量向量，$A \in \{0,1\}$ 是治疗，$Y \in \{0,1\}$ 是结局；$g(A, W) = \Pr(A \mid W)$ 是倾向模型，$\bar Q(A, W) = \mathrm{E}(Y \mid A, W)$ 是结果模型，$\bar Q_0(W) = \mathrm{E}(Y \mid A=0, W)$、$\bar Q_1(W) = \mathrm{E}(Y \mid A=1, W)$。

① 初始估计（nuisance 拟合，SuperLearner 完成）

$\hat g(A, W) = \mathrm{SuperLearner}\bigl[\Pr(A \mid W);\ \text{glm, gam, xgboost}\bigr]$
$\hat{\bar Q}_0(W) = \mathrm{SuperLearner}\bigl[\mathrm{E}(Y \mid A=0, W)\bigr]$,    $\hat{\bar Q}_1(W) = \mathrm{SuperLearner}\bigl[\mathrm{E}(Y \mid A=1, W)\bigr]$

② 智能缺失函数（clever covariate / fluctuation variable）

$H_a(W) = \dfrac{I(A=a)}{\hat g(A=a, W)} - \dfrac{I(A=1-a)}{\hat g(A=1-a, W)}$,    $a \in \{0, 1\}$

③ 靶向更新（targeting step）：以 $H_a(W)$ 为偏移参数，对初始 $\hat{\bar Q}_a^*$ 做 logistic 波动拟合，解出 $\hat\epsilon$。

$\mathrm{logit}\,\hat{\bar Q}_a^{\star}(W) = \mathrm{logit}\,\hat{\bar Q}_a(W) + \hat\epsilon \cdot H_a(W)$
最小化 $\sum_i \bigl[Y_i - \hat{\bar Q}_{A_i}^{\star}(W_i)\bigr]^2$，唯一参数 $\hat\epsilon$。

④ 因果对比度估计（本研究：$\ln\mathrm{RR}$ 尺度）

$\widehat{\ln\mathrm{RR}}_{\mathrm{TMLE}} = \dfrac{1}{n} \sum_{i=1}^{n}\Bigl[\mathrm{logit}\,\hat{\bar Q}_1^{\star}(W_i) - \mathrm{logit}\,\hat{\bar Q}_0^{\star}(W_i)\Bigr]$

⑤ 高效影响函数（EIF，给出 95% CI 与标准误）

$\mathcal{D}(O) = H_1(W)\bigl\{Y - \hat{\bar Q}_1^{\star}(W)\bigr\} - H_0(W)\bigl\{Y - \hat{\bar Q}_0^{\star}(W)\bigr\} + \mathrm{logit}\,\hat{\bar Q}_1^{\star}(W) - \mathrm{logit}\,\hat{\bar Q}_0^{\star}(W) - \psi$
其中 $\psi = \widehat{\ln\mathrm{RR}}_{\mathrm{TMLE}}$；$\mathrm{Var}(\widehat{\ln\mathrm{RR}}) \approx \mathrm{Var}\bigl[\mathcal{D}(O)\bigr]/n$，由此得 $\mathrm{SE}$ 与 95% CI。

⑥ 双重稳健性公式（关键性质）

$\widehat{\psi}_{\mathrm{DR}}^{\mathrm{AIPW}}(O) = \underbrace{\bigl[\hat{\bar Q}_1(W) - \hat{\bar Q}_0(W)\bigr]}_{\text{结果模型贡献}} + \underbrace{\dfrac{A}{\hat g(1,W)}\bigl\{Y - \hat{\bar Q}_1(W)\bigr\} - \dfrac{1-A}{\hat g(0,W)}\bigl\{Y - \hat{\bar Q}_0(W)\bigr\}}_{\text{倾向模型加权残差}}$
⇒   若 $\hat{\bar Q}$ 或 $\hat g$ 其中之一设定正确（其余可有任意有限维误设），$\widehat{\psi}_{\mathrm{DR}}^{\mathrm{AIPW}} \xrightarrow{p} \psi$。

上式即增强反概率加权估计量（AIPW / 双机器学习 DML 估计量），是 TMLE 的渐近等价表达。它把结果模型的预测与倾向加权残差加在一起，两者各自独立吸收一个 nuisance 模型的偏倚。只要其中一个 nuisance 模型正确，整个估计量就一致，这就是所谓双重稳健（doubly robust）的精确含义。TMLE 再通过靶向步骤把估计量投影到使 EIF 期望为 0 的位置，从而同时获得半参数有效方差下界（van der Laan & Rose, 2011; van der Laan & Rubin, 2006）。

⑦ TMLE 的双重稳健与半参数有效两个性质互不蕴含，但 TMLE 同时拥有。双重稳健只保证一致性（即渐近无偏），半参数效率保证方差达到 Cramer–Rao 下界（即同任务中最小的渐近方差）。朴素回归与 IPTW 既不双稳健也不半参数有效，AIPW 估计量双稳健但需手动求解，TMLE 把两者打包成自动等于双稳健加半参数有效。这就是本研究把它定为分析层主方法的原因。

指标词典（深度解释） The metrics, defined and demystified

每个指标给出三件套：严谨定义 → 数学符号 → 通俗解释（含比喻）。所有指标都只需负对照估计与主估计两个输入，无需额外数据。

① 偏倚分数 Bias Fraction (BF)：主指标（本论文提出）
严谨定义：在“校准后总信号 = 偏倚 + 残留效应”中，系统偏倚所占的份额。
BF = |μ̂B| / ( |μ̂B| + |ψ̃| ) ∈ [0, 1]
BF = 1 ⇔ 校准后效应恰为 0（信号完全由偏倚构成）；BF = 0 ⇔ 未估计到任何系统偏倚。BF 与偏倚效应比一一对应：BF = BER / (1 + BER)。
🍰 通俗解释（蛋糕比喻）：校准后剩下的信号是一块蛋糕，偏倚和残留效应各切一块。BF 就是“偏倚切走了几成”。BF = 0.91 意思是：这块蛋糕的九成一是偏倚，真正的“效应”只剩不到一成。BF 有界，永远不会爆出“无穷大”这种尴尬数字。
② 偏倚效应比 Bias-Effect Ratio (BER)：辅助指标（本论文提出）
严谨定义：系统偏倚与校准后残留效应的大小之比（无界）。
BER = |μ̂B| / |ψ̃| = BF / (1 − BF) ∈ [0, ∞)
⚖️ 通俗解释（倍数比喻）：“偏倚是残留效应的多少倍”。BER = 9.6 读作“偏倚大约是残留效应的十倍”。倍数的好处是直观，坏处是当残留效应趋近 0 时它会爆炸（甚至 ∞），所以 v34 起只作辅助展示，分区判断全部交给有界的 BF。本研究的模拟给出直接证据：在 48 个真实效应恰为零的条件（BFtrue = 1）下，BER 的相对偏倚根本无定义（真值是 ∞），而 BF 仍可正常估计（平均相对偏倚 −30.2%、RMSE 0.34，因 [0,1] 上限效应而向下收缩）。这正是论文选择 BF 作主指标的核心理由之一。
③ 观测偏倚分数 Observed Bias Fraction (OBF)：描述性对照
严谨定义：偏倚占未校准（观测）估计的份额。
OBF = |μ̂B| / |ψ̂obs| ∈ [0, ∞)
🔎 通俗解释：“论文里报告的那个 RR 里，偏倚占几成”。β 受体阻滞剂病例：OBF = 0.190 / 0.184 ≈ 1.03，估计出的偏倚比整个观测关联还大一点，即“那个 0.83 的 RR 几乎可以被偏倚全盘解释”。OBF 无界，仅作描述。
④ 校准 P 值 Calibrated p-value
严谨定义：把观测估计对照经验零分布（而非标准正态）计算的双侧 P 值，检验“校准后效应是否可区分于零”。P > 0.05 = 扣除偏倚后无证据支持真实效应；P < 0.05 = 扣除偏倚后仍有可区分的效应。
🚦 通俗解释：它是一个二元开关，只回答“扣除偏倚后是否有证据支持真实效应”。BF 则是一个连续刻度，量化偏倚占校准后信号的比例。两者互补：论文应同时报告。
⑤ 三区分类 Three-zone classification
严谨定义：基于 BF（等价于 BER）的启发式分区，CI 跨区时取更谨慎的一侧。
效应主导 effect-dominated：BF < 1/3（残留效应 ≥ 偏倚 2 倍） 混合区 mixed：1/3 ≤ BF ≤ 0.5（偏倚与效应混在一起，难分彼此） 偏倚主导 bias-dominated：BF > 0.5
🎯 通俗解释（三色仪表盘）：绿区（效应主导）“信号盖过噪声，可谈疗效”；黄区（混合）“偏倚与效应混在一起、势均力敌，必须谨慎并做敏感性分析”；红区（偏倚主导）“这份数据不足以支持因果结论”。注意：红区 ≠ 药物无效，只是“这份数据里分不清效应与偏倚”。
⑥ Fieller 置信集 Fieller confidence set
严谨定义：对带符号比值 ρ = μ̂B/ψ̃ 的置信集，由不等式 (m₁−ρm₂)² ≤ z²α/2(v₁₁−2ρv₁₂+ρ²v₂₂) 定义。当分母 ψ̃ 太小时，它会诚实地退化为外集、空集或全直线。
🪞 通俗解释：普通区间在分母趋近 0 时可能给出误导性的有限区间；Fieller 集则对该比值给出诚实的置信区域，该多宽就多宽，该无界就无界。β 受体阻滞剂病例的 Fieller 集为 (−∞, −1.62]∪[1.45, ∞)，意思是“比值只能排除中间一小段，其余全都与数据相容”：这正是“校准后效应≈0”时该有的诚实回答。
⑦ bootstrap 中位数点估计 Bootstrap-median point estimate
严谨定义：在 logit（BF）/ log（BER）尺度取 bootstrap 分布的中位数再反变换。点估计与置信区间出自同一个分布，因此点估计不可能落在自己的 CI 之外。
🔧 通俗解释：早期版本曾出现过“点估计 413.2 > 自己的 CI 上限 204.8”的怪象（原始比值与 bootstrap 分布脱节）。改用中位数后，这种自相矛盾从机制上被消除。

A.3 关于「窄 CI / 宽 CI」的处理

包内部把经验查照表里的窄 CI 列与宽 CI 列读出来取保守最大值，输出中只剩一个数字 P(bias-dominated)。print() 与 explain() 都不会出现「narrow / wide」字样，临床医生无需决定区间宽度。层 2 的 BF 点估计与 95% CI 仍以图形方式画出，方便需要复核的读者核对查照表取值。

A.4 两层各自的含义（自动写入输出）

每个 ber_screen 对象在打印或调用 explain() 时都会包含以下两段：

  • 层 1（信号是否存在） · 校正 P 值衡量「扣掉系统偏倚之后，这个关联是否还区别于随机」。P < 0.05 才进入层 2；否则判为「证据不足」，不再读 BF。
  • 层 2（其中多少是偏倚） · 在信号确实存在的前提下，BF 衡量「这个信号里有多大份额来自系统偏倚」。配合其 95% CI 与经验查照表，给出一个保守的 P(bias-dominated)，落入四档判语之一。
对临床读者来说最关键的两件事：① 校正 P 值是否 < 0.05，决定要不要继续读下去；② 保守 P(bias-dominated) 是否 < 0.15（绿）/ < 0.45（橙）/ < 0.65（红）/ ≥ 0.65（红），决定它是哪一档。其余数字（BF、CI 宽度）只是帮助定位查照表取值的中间量。

方法学溯源与修订问答 Methodological traceability & revision Q&A

这一部分提炼自第38版成稿期间的多轮人机协作讨论，集中回应四个最容易被审稿人或合作者追问、也最容易被误判的方法学问题：P0 负对照配置不一致的真相、LTMLE 改成 TMLE 对仿真的影响、横向节导致文档截断的根因，以及 GDMT A+ 改造的对齐范围。它们都不改变已发布的两层判读结论，但直接影响读者对「结论到底有多稳」的判断。

Q1 · 「负对照与主分析 LTMLE 配置不一致」这个 P0，真实含义是什么

结论先行：它不是负对照的问题，而是 GDMT 主分析还残留一点纵向设置。2026-09-04 的 #69 复查把代码翻到底层后发现，主分析其实已经是横截面 TMLE（单点治疗 A_W0、仅基线协变量、无删失节点、单一 glm learner、非生存结局），与摘要和 Methods 里写的「纵向 LTMLE + Super Learner + 时变混杂 + 删失」四处断言全部不符。唯一残留的不一致，是 GDMT 仍带 survivalOutcome=TRUE。

之前担心的因果链（负对照比主分析更弱 → μ̂B 偏大 → BF 被高估 → 整篇偏倚量化虚高）在把 GDMT 也升级为横截面 TMLE 之后已消除。治本动作是让 GDMT 与主分析、12 个负对照走同一套横截面 TMLE，而不是去改负对照。

附带提醒：Methods 那四处断言（纵向、Super Learner 三 learner、时变混杂、删失）至今仍与代码不符，需要要么改 Methods 文案、要么改回真正的纵向 LTMLE 才能自洽。这是待裁决的写作项，不影响本讲解器的数字。

Q2 · 把主分析从 LTMLE 改成 TMLE，会不会动到第二部分的 96 万次模拟

不会，零影响。第二部分（指标、覆盖、判别力）是纯蒙特卡洛：960 条件 × 1000 重复 = 96 万次独立重复，每次都从经验零分布（μB, σB）加设计真值独立生成数据、再跑 BF 两层判读。代码里不调用任何 ltmle 或 TMLE 拟合函数，与设计用的是哪种估计量完全无关。

估计量修订只改变第三部分两个实证病例（BB、GDMT）的 RR / BF 数字，不动第一、二部分的指标定义、覆盖率、判别力结论。这是 #74 复核确认过的，所以本轮把 GDMT 改为横截面 TMLE 后，第一、二部分的图表与结论一字未动。

Q3 · 为什么改完的 docx 在腾讯文档编辑器里打不开、论文后部丢失

根因是横向节，不是内容或文件损坏。投稿版 docx 在 Fig2 + Table2 之后含一个 w:orient="landscape" 的横向节。腾讯文档本地编辑器在打开或保存含横向节的 docx 时会静默截断该节之后的全部内容（Discussion / Limitations / Conclusions / Word Count 全丢），而文件大小、段数看起来都正常，极难察觉。

之前的 #43/#44 修复只把页面尺寸从 A4 改成 Letter、调了页边距，没有消除横向节本身，所以这次仍然打不开，证明那次修复是错的。本轮治本是双版本工作流：

① 投稿版保留横向节，仅供上传 JAMA；② 人机双写协作版用新增的 _post_portrait_for_coauthor.py 剥离横向节（landscape sectPr + 退化空 sectPr），可完整打开、不丢内容。两条后处理脚本互斥：投稿跑 landscape、协作跑 portrait，重渲染后按需跑对应的一条。

Q4 · GDMT A+ 改造到底对齐了什么，改完判读变了吗

对齐范围（A+ 即「与主分析、12 负对照完全一致」）：GDMT 升级为单点治疗 A_W0、无删失节点、survivalOutcome=FALSE、SL.library="SL.glm"、仅基线协变量；并把队列从 15,053 例对齐到 14,677 例（与主分析、Table 3 同一队列）。全链重跑后：

GDMT：未校准 RR 0.68、校准后 0.83、cal_p 0.045、BF 0.510（95% CI 0.356–0.603）、P(bias-dominated) 0.648、查表桶 7、判读仍「competitive, no verdict」。BB：cal_p 0.946、BF 0.907（微整）。

判读变了没有：方向没变，GDMT 仍是「不能用作效应证据、只能作假设生成」；但数字语义变了，从原先「显著（p=0.007）」变成「不显著、压在边界（p=0.045）」，BF 反而从 0.45 升到 0.51，更靠红区。换句话说，A+ 让 GDMT 的偏倚主导证据更干净，而不是更弱。

与讲解器同步的单一来源。本讲解器里所有实证数字都内联在 JS 对象 N.part3.cases（BB 为 [0]、GDMT 为 [1]），决策台与案例结果框都从它读取。所以本轮同步只需改这一处，计算器、决策台、案例框会自动一致，无需逐个改函数。
