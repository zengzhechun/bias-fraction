## 三、负对照与主分析配置不一致

### 3.1 是什么问题

两侧读的是**两个不同的队列文件**，行数相同、结局相同、协变量相同，
但**治疗变量 `A_W0` 的含义不同**：

| | 主分析 | 12 个负对照 |
|---|---|---|
| 输入文件 | `ltmle_wide_K2_guideline.rds` | `ltmle_wide_K2.rds` |
| `A_W0` 的口径 | 只计入 carvedilol / metoprolol succinate / bisoprolol（`scripts/restrict_guideline_bb.R` 用 `guideline_dose_pct_max >= 50` 覆盖原 `A_W0`） | 计入全部 β 受体阻滞剂 |
| `A_W0 >= 2` 占比（`Y_W0==0`，n=14,677） | **12.07%**（全样本 11.82%） | **43.46%**（全样本 43.01%） |

也就是说，同一个「达到 50% 目标剂量」的阈值，作用在**两个不同的剂量口径**上；
K2 文件里 `A_W0 = 2` 的 3,993 例，在 guideline 编码下是 0。这是**两个不同的暴露对比**。

**此前记录的「两点治疗 + 删失节点 + 参数化 g-formula」说法经核对不成立**，
已更正：两侧都是单点 `Anodes = "A_W0"`、无 `Cnodes`、仅基线协变量、
`survivalOutcome = FALSE`、同样排除宽限期死亡。除暴露定义外只有一处次要差异：
`SL.library` 主分析问题 1 用 `c("SL.glm","SL.glmnet")`，负对照与问题 2 用 `"SL.glm"`。

### 3.2 要不要重跑：**要**

OHDSI 经验校准的前提是负对照与目标估计走**同一个处理对比**，现在不是。
用 `R/90_diag_nc_exposure_consistency.R` 把同一套负对照结局分别挂到两个队列上重拟合，
再用 `R/91_diag_matched_null_impact.R` 走一遍已发表管线（该脚本的 K2 一路**逐位复现**
`output/data/bsr_results_v35.rds` 的 `mu_bias`、`sigma_bias`、`cal_p`、`bf` 与 bootstrap 区间，
偏差为 0，可作自校验），得到：

| 项目 | 已发表（K2 面板） | 配平后（guideline 面板） |
|---|---|---|
| μ̂_B | −0.1905 | **−0.1678**（绝对量降 11.9%） |
| σ̂_B | 0.0680 | **0.1129**（升 66.1%） |
| 问题 1 校准 P | 0.946 | 0.894 |
| 问题 1 BAF（95% CI） | 0.907 [0.739, 0.993] | 0.875 [0.385, 0.992] |
| 问题 2 校准 P | **0.0452（通过 layer 1）** | **0.1026（不再通过 layer 1）** |
| 问题 2 BAF（95% CI） | 0.510 [0.356, 0.603] | 0.460 [0.186, 0.619] |
| 问题 1 判定 | not usable as effect evidence | not usable as effect evidence |
| 问题 2 判定 | competitive, no verdict | competitive, no verdict |

**判定标签两问都不变**，所以重跑不改变论文结论；但下面四处描述会变：

1. 问题 2「passed layer 1」→ 不再通过；
2. 问题 2「点估计略偏倚主导（>0.5）」→ 0.460，落在混合区；
3. 两问 BAF 可信区间显著展宽；
4. **配平后面板有 2/12 个负对照转为阳性**（Fall without fracture RR 1.195、Gout RR 1.136），
   正文「all 12 negative controls showing protective or null associations」需改，
   `NUM$part3$nc$all_protective` 也会由 TRUE 变 FALSE。
