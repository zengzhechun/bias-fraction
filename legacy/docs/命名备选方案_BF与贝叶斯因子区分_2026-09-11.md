# 偏倚分数（Bias Fraction）命名与简写备选方案

**文档性质**：命名建议，仅备选方案，**未同步到任何稿件**。
**日期**：2026-09-11
**背景**：本研究的核心指标称为 Bias Fraction，现用简写 **BF**。BF 在统计学与医学文献中已被 **Bayes Factor（贝叶斯因子）** 长期占用，且贝叶斯因子在方法学、心理学、神经影像与部分临床研究中出现频率不低。两者同处"证据强度/模型比较"语义场，检索与阅读时容易混淆。

---

## 一、问题界定

需要区分的不是"名字是否好听"，而是三个可验证的检索与引用问题：

1. **检索区分度**：在 PubMed / Google Scholar 检索 `BF` 时，本研究能否被找到。
2. **同在句内的歧义**：一句话里同时出现"BF"与"贝叶斯因子"时，读者无法判断指代。
3. **表格与摘要的自明性**：摘要、表格列头、图注中只写简写时，陌生读者能否推断含义。

现状评估：第 3 项最严重。正文 Table 2 的列头是 `Sens (BD)` / `Spec (BD)` 这类已有区分度，但正文与摘要中的 `BF = 0.906` 这类写法，在只读摘要的读者眼中与贝叶斯因子无法区分。

---

## 二、评价标准

| 标准 | 说明 |
|---|---|
| 无冲突 | 不被统计学或本项目所在临床领域的高频缩写占用 |
| 自解释 | 看到简写能大致猜到含义，或名字本身即含义 |
| 可朗读 | 能在学术报告中自然读出，不靠逐字母拼读 |
| 可检索 | 作为字符串在数据库中稀有，检索即命中 |
| 改动成本 | 需要改动的稿件、代码、图表、R 包命名范围 |

补充一条**本项目内部约束**：代码中 `BB` 已被 beta-blocker 占用（`BB$bf`），`BSR` 已被底层比值 `|μ_B|/|ψ̃|` 占用，`bsr_*` 是函数前缀。新简写不得与这三者冲突。

## 三、方案对比

### A 组：保留"Bias Fraction"名称，只换简写

| 简写 | 读法 | 冲突评估 | 备注 |
|---|---|---|---|
| **BFrac** | "B-frac" | 无已知冲突 | 改动最小，与公式 `BF` 视觉连续；缺点是仍以 BF 开头，摘要首现仍需展开 |
| **BFr** | "B-F-R" | 无已知冲突 | 需逐字母读，朗读性差 |
| **BiF** | "bif" | 无 | 三字母易被当作单词，视觉辨识好 |
| **βF** | "beta-F" | 与回归系数 β 相邻，易混 | 希腊字母进入列头会带来排版问题 |

### B 组：改名，用"share / attribution"语义

"fraction" 与 "share" 在本指标上完全等价，而 share 更口语、更少被占用。

| 名称 | 简写 | 读法 | 冲突评估 |
|---|---|---|---|
| **Bias Share** | BS | "B-S" | **否决**：BS 在临床交流中已被"血糖""肠易激"等占用，且口语不雅 |
| **Bias Share of the Signal** | BSS | "B-S-S" | BSS 与盲源分离（blind source separation）冲突 |
| **Bias Attribution Fraction** | **BAF** | "baf" | 与 barrier-to-autointegration factor（BAF 蛋白）弱冲突，非同一领域 |
| **Attributable Bias Fraction** | **ABF** | "A-B-F" | 无强冲突 |
| **Systematic Bias Fraction** | **SBF** | "S-B-F" | 与 simulated body fluid 弱冲突 |
| **Bias Contribution Fraction** | BCF | "B-C-F" | BCF 与 Bayes 计算因子近似，反而更近 BF，**否决** |

### C 组：改名，用"dominance / index"语义

本指标本质是"偏倚在标定信号中占主导的程度"，因此 dominance 语义也贴切。

| 名称 | 简写 | 读法 | 冲突评估 |
|---|---|---|---|
| **Bias Dominance Index** | BDI | "B-D-I" | **否决**：BDI 在精神科/内科文献中被 Beck Depression Inventory 长期占用 |
| **Bias Dominance Fraction** | BDF | "B-D-F" | 与 BD（bias-dominated）三区分类的命名天然呼应；无强冲突 |
| **Bias Dominance Ratio** | BDR | "B-D-R" | 无强冲突，但"ratio"与有界 [0,1] 的"fraction"语义不符 |
| **Bias Fraction Index** | BFI | "B-F-I" | 保留 BF 词根，另外两字母提供区分度 |

### D 组：造词（最强检索区分度）

| 名称 | 形态 | 评估 |
|---|---|---|
| **Bifrac** | 单词 | 检索唯一性最高，作为软件/R 包名友好；缺点是学术写作中首次出现需明确定义，且看起来像产品名 |
| **BiaShare** | 单词 | 同上，但"Bia"可能被误读为 bias 的拼写错误 |

## 四、推荐

### 首选：**Bias Attribution Fraction（BAF）**

理由：

1. **语义最准**。本指标的公式 `|μ̂_B| / (|μ̂_B| + |ψ̃|)` 表达的是"在标定后的信号总量中，归属于偏倚的那一部分"，attribution 比 fraction 或 share 更准确地传达"归因"这一层含义。
2. **无实质冲突**。BAF 在心血管与流行病学文献中未被主要缩写占用；与分子生物学的 BAF 蛋白不构成同领域歧义。
3. **自解释**。看到 BAF 的读者能同时推断出"bias"和"fraction/attribution"两个要素，比 BF 更少依赖上下文。
4. **与既有术语体系兼容**。副标题仍可写 "The Bias Fraction"，即正文沿用 Bias Fraction 作为概念名，只在简写层面改用 BAF：`Bias Attribution Fraction (BAF), the bias fraction of the calibrated signal`。

### 次选：**Bias Dominance Fraction（BDF）**

理由：与指标自身定义的三分区（bias-dominated / mixed / effect-dominated）在语言上完全同源，读者读到 BDF 会立刻联想到 "bias-dominated" 这一本文核心概念，而不会是贝叶斯因子。若最终决定把三区分类提升为论文主线，BDF 的一致性优于 BAF。

### 保守方案：**BFrac**

理由：不改变名称，不改动任何正文措辞，只把简写从 `BF` 换成 `BFrac`。改动成本最低（约 200 处机械替换 + 图表列头），但只是"绕过"而非"解决"冲突：在摘要首现处仍需写全称。

### 单符号方案（若期刊允许数学符号）

用 **φ** 或 **κ_B** 作为指标符号，正文写 `φ = |μ̂_B| / (|μ̂_B| + |ψ̃|)`。优点是彻底脱离字母缩写冲突；缺点是 JAMA 系列稿件对正文数学符号的容忍度有限，且读者检索困难。仅在指标本身成为论文唯一贡献、符号会反复出现时值得考虑。

## 五、若采纳，需同步改动的位置（清单，供决策参考）

按改动量从小到大：

1. **仅改简写（BFrac 方案）**：6 份 qmd 正文与表格列头、3 份 Cover Letter、互动讲解器 HTML、`v39_dual_view*.csv` 的规则标签、`output/figures/v39/` 内图注。
2. **改名称（BAF / BDF 方案）**：上述全部，外加摘要、Key Points、标题（现标题以 "The Bias Fraction" 结尾）、R 包 `biasratio` 的函数前缀（`bsr_*` 与 `bf_*`）、`v39_all_numbers.json` 的字段名。
3. **改符号（φ 方案）**：上述全部，外加所有图表坐标轴标签与 LaTeX 公式的重排。

其中第 2、3 项会连带影响已在审的 biasratio R 包接口，属**破坏性变更**，建议在预印本发布前一次性决定，避免两套命名并存。
