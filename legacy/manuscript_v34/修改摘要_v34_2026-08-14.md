# 修改摘要 v33 → v34（2026-08-14）

依据审稿意见（`manuscript_v33/Submit/JAMA Network Open/审稿意见_JAMA_NW_Open_v33_2026-08-14.md`）与第二轮讨论（BF 主推 / BER 辅助方案），v34 完成以下修改。

## 一、方法学改动（核心）

1. **主指标改为 Bias Fraction（BF），BER 降为辅助比**
   - $\mathrm{BF}=|\hat\mu_B|/(|\hat\mu_B|+|\tilde\psi|)\in[0,1]$，$\mathrm{BF}=\mathrm{BER}/(1+\mathrm{BER})$
   - 三区阈值改为：bias-dominated BF>0.5；mixed 1/3≤BF≤0.5；effect-dominated BF<1/3（分区与 BER 阈值一一对应，模拟分类准确率全部不变，无需重跑）
   - 删除"BER=∞ 归为 bias-dominated"特例（BF 在零效应处 = 1，天然有限）
   - 一致性性质删去 "provided ψ≠0" 限制：BF 映射在 ψ=0 处连续，一致性覆盖全参数空间（eAppendix 10）
   - 旧的 "bias fraction"（以观测值为分母）改名 **Observed Bias Fraction (OBF)**，作为描述性对照量（eAppendix 1）

2. **点估计与 CI 同源**
   - 点估计改为 logit 尺度 bootstrap 中位数反变换，消除 v33 中"点估计落在自身 bootstrap CI 之外"的病理（SL 完整库 413.2 > 204.8）
   - CI 为 logit 尺度 bootstrap 2.5/97.5 分位（与 BER 的 log 尺度 CI 等价，免费复用）

3. **新增 Fieller 定理置信集**（`bsr_fieller()`）作为分母近零时的稳健性兜底
   - BB：外集 $(-\infty,-1.62]\cup[1.45,\infty)$（分母近零 → 比值频数学意义不可精确识别，诚实报告）
   - GDMT：内集 [0.42, 1.80]，跨 1，与 mixed 一致

4. **模拟在 BF 尺度重算偏倚/RMSE**（分类准确率不变）
   - 无违反：BF 平均相对偏倚 **+2.1%**（逐配置 +1.8%~+2.3%），对比 BER 尺度 +137%~+319%
   - 30% 违反：−31.7%（向 0.5 衰减，方向乐观）；BF 尺度 RMSE 均值 0.135 / 中位 0.119
   - 文档化"30% 违反"实际实现为 33.3% (K=12) / 32.0% (K=25) 及共同随机数方案
