偏倚分数 BF：用负对照量化观察性因果估计中的系统性偏倚

用负对照（negative controls）校准观察性研究中的系统性偏倚，并用一个介于 0 与 1 之间的数——偏倚分数（bias fraction, BF）——回答：
"校准之后剩下的信号里，到底有多少是真实效应，有多少是偏倚？"

① 为什么需要这个指标 Why this metric exists

真实世界证据（real-world evidence, RWE）越来越多地进入指南与监管决策。研究者用目标试验模拟（target trial emulation, TTE）、TMLE 等方法，尽可能模仿随机试验。但这些方法共同依赖一个关键假设：无未测量混杂假设（no unmeasured confounding）——即"所有影响治疗与结局的共同原因都已被测量并调整"。

一项调查数据：对 237 项 TTE 研究的横断面调查显示，只有 30.8% 的研究用统计方法评估了未测量混杂（Ren et al., JAMA Network Open 2026）。也就是说，近七成的 TTE 研究没有任何经验性的偏倚检查就发表了因果结论。

健康依从者效应：药物流行病学中的典型混杂现象

健康依从者效应（healthy adherer effect）：依从治疗的患者，即使吃的是安慰剂，结局也更好——因为他们本身更健康、更自律、医疗资源更好。观察性研究中，"吃够了药"这件事本身就携带了大量与药物无关的预后信息。

本论文的病例（MIMIC-IV）：在心衰住院患者中比较"达到 ≥50% 目标剂量 β 受体阻滞剂"与"<50%"。
  • 未校准的 TMLE 估计：RR = 0.83，看起来 β 受体阻滞剂把 1 年死亡降低了约 17%——与随机试验的表面结论相容。
  • 但"能达到目标剂量"的患者，本身就是更健康的患者。
  • 12 个负对照结局（该药"不可能"影响的结局，如白内障、痛风）全部呈保护性关联——这就是系统性偏倚存在的直接证据。

现有校准方法（校准 p 值）的局限

OHDSI 的经验校准（empirical calibration）框架（Schuemie et al. 2014, 2018）的做法分两步：第一步，用负对照估计出系统偏倚的分布（均值 μ̂B 和波动 σ̂B）；第二步，把观测估计放进这个"偏倚分布"里重新检验，得到一个校准 p 值（calibrated p-value）。

校准 p 值到底在说什么？（划重点）
  • 校准 p > 0.05：扣除系统偏倚之后，剩下的效应小到与"零"没有统计上可区分的差别 → "没有证据表明该治疗存在真实效应"。注意：这绝不表示"没有偏倚"。恰恰相反，此时偏倚往往很大——正是它把估计"拨"到了零附近。
  • 校准 p < 0.05：扣除偏倚之后，仍然有与零可区分的残余效应 → "有证据支持真实效应"。
它的局限：这是一个"是 / 否"的二元判决，回答不了下一个问题——"扣除的偏倚有多大？剩下的效应又有多大？" 两个截然不同的情形会给出同一个"不显著"：
"校准后不显著"的两种含义：
① 效应被偏倚淹没——真实效应存在，但偏倚太大，校准后信号被抹平；
② 本来就无效——校准正确地移除了偏倚，剩下一个真实的零效应。
校准 p 值无法区分这两种情况。BF 正是为区分它们而设计的连续量：它直接报告"偏倚占校准后信号的几成"。

② 核心概念 Core concepts

负对照结局 Negative control outcome
严谨定义：与主结局共享同一套混杂结构、但不可能被治疗因果影响的结局。若治疗与负对照也出现关联，该关联只能来自混杂（或偏倚）。
💡 通俗解释：负对照的真实效应已知为零。若治疗与负对照也出现关联，该关联不可能来自药物作用，只能来自研究设计中的系统偏倚。
经验零分布 Empirical null distribution
严谨定义：用 K 个负对照的估计值 (γ̂k, τ̂k) 通过最大似然拟合的分布 N( μ̂B, √τ̂k² + σ̂B² )，其中 μ̂B 是平均系统偏倚，σ̂B 是对照间偏倚的异质性。
💡 通俗解释：负对照集合刻画了偏倚的分布特征。12 个负对照全部偏向保护一侧，说明研究设计会系统性地高估保护作用。
偏倚交换性 Bias exchangeability
严谨定义：在给定已测协变量的条件下，影响主估计的残留偏倚的分布 ≈ 支配负对照估计的偏倚分布。这是整个方法的关键假设，与它所诊断的"无未测量混杂"一样无法用数据直接验证。
💡 通俗比喻："同一把尺子"假设——负对照和主结局被同一套混杂机制污染。如果负对照的偏倚是"尺子 A"造成的，而主结局的偏倚来自"尺子 B"，校准就会用错尺子。

偏倚共享结构（交互式因果图） Shared bias structure

图中带箭头的线表示影响方向：实线箭头 = 因果路径；虚线箭头 = 偏倚路径；红叉 = 负对照假设"不存在"的治疗→对照因果路径。把鼠标移到节点上查看解释。关键：U 同时指向 A、Y 与 Nk——若未测量 U 存在，A 与 Y 之间的关联就会被偏倚污染；而 Nk 上观察到的"假关联"正是这条偏倚路径的读数。

校准做什么 What calibration does

ψ̃ = ψ̂obs − μ̂B 校准后（去偏倚）效应 = 观测估计 − 估计的系统偏倚（均在 log RR 尺度）

负对照告诉我们研究设计平均会把估计向保护方向偏移多少（μ̂B）；校准就是从观测值中减去这个系统偏移，并把偏倚的不确定性（σ̂B）并入标准误：

σ̃ = √σ̂obs² + σ̂B² 校准后标准误 = 抽样误差与系统误差不确定性的合成（根号下是两者的平方和）

BF 与 BER 是怎么"站在负对照的肩膀上"的（一句话总结）： OHDSI 的 EmpiricalCalibration 包解决的是"有没有偏倚"（μ̂B）和"扣除偏倚后还剩不剩效应"（校准 p 值，二元判决）。BF/BER 不引入任何新数据，只是把包已经算出的两个量——μ̂B（偏倚）与 ψ̃ = ψ̂obs − μ̂B（校准后残留效应）——做成一个比值：BF = |μ̂B| / (|μ̂B| + |ψ̃|)（偏倚占校准后信号的几成，有界 0–1）、BER = |μ̂B| / |ψ̃|（偏倚是残留效应的几倍，无界）。这样就把"是/否"的判决，扩展成了对未测量偏倚的连续量化：偏倚有多大、剩下的效应有多大、二者谁占主导。
计算代码（R，与论文输出一致）： 
# ① EmpiricalCalibration 包：用 12 个负对照估计"系统偏倚分布"
null_fit <- EmpiricalCalibration::fitNull(nc_log_rr, nc_se_log_rr)
mu_b    <- null_fit[1]   # 平均系统偏倚 μ̂_B = -0.190（log RR 尺度）
sigma_b <- null_fit[2]   # 对照间偏倚的异质性 σ̂_B = 0.068

# ② 校准主估计：从观测估计中减去系统偏倚
log_rr_cal <- log_rr_uncal - mu_b        # ψ̃ = -0.184 - (-0.190) = +0.0063 → RR 1.006
cal_p      <- EmpiricalCalibration::calibrateP(null_fit, log_rr_uncal, se_log_rr)
                                         # 校准 p = 0.943：扣除偏倚后与零无区别

# ③ BF 与 BER（biasratio 包 v0.2.0；两个量互为变换，无需新数据）
bf  <- abs(mu_b) / (abs(mu_b) + abs(log_rr_cal))   # = 0.906（bootstrap 中位数）
ber <- abs(mu_b) / abs(log_rr_cal)                 # = 30.4（原始比值；中位数 9.6）

# ④ 置信区间：只重抽样 12 个负对照 × 2000 次，logit（BF）/ log（BER）尺度取分位数
#    → BF 95% CI [0.74, 0.99]，整个区间 > 0.5 → 偏倚主导区

④ 指标词典 The metrics, defined and demystified

每个指标给出三件套：严谨定义 → 数学符号 → 通俗解释（含比喻）。所有指标都只需负对照估计与主估计两个输入，无需额外数据。

① 偏倚分数 Bias Fraction (BF) —— 主指标
严谨定义：在"校准后总信号 = 偏倚 + 残留效应"中，系统偏倚所占的份额：
BF = |μ̂B| / ( |μ̂B| + |ψ̃| )  ∈ [0, 1]
BF = 1 ⇔ 校准后效应恰为 0（信号完全由偏倚构成）；BF = 0 ⇔ 未估计到任何系统偏倚。BF 与偏倚效应比一一对应：BF = BER / (1 + BER)。
🍰 通俗解释（蛋糕比喻）：校准后剩下的信号是一块蛋糕，偏倚和残留效应各切一块。BF 就是"偏倚切走了几成"。BF = 0.91 意思是：这块蛋糕的九成一是偏倚，真正的"效应"只剩不到一成。BF 有界，永远不会爆出"无穷大"这种尴尬数字。
② 偏倚效应比 Bias-Effect Ratio (BER) —— 辅助指标
严谨定义：系统偏倚与校准后残留效应的大小之比（无界）：
BER = |μ̂B| / |ψ̃| = BF / (1 − BF)  ∈ [0, ∞)
⚖️ 通俗解释（倍数比喻）："偏倚是残留效应的多少倍"。BER = 9.6 读作"偏倚大约是残留效应的十倍"。倍数的好处是直观，坏处是当残留效应趋近 0 时它会爆炸（甚至 ∞），所以 v34 起只作辅助展示，分区判断全部交给有界的 BF。
③ 观测偏倚分数 Observed Bias Fraction (OBF) —— 描述性对照
严谨定义：偏倚占未校准（观测）估计的份额：
OBF = |μ̂B| / |ψ̂obs|  ∈ [0, ∞)
🔎 通俗解释："论文里报告的那个 RR 里，偏倚占几成"。β 受体阻滞剂病例：OBF = 0.190 / 0.184 ≈ 1.03——估计出的偏倚比整个观测关联还大一点，即"那个 0.83 的 RR 几乎可以被偏倚全盘解释"。OBF 无界，仅作描述。
④ 校准 p 值 Calibrated p-value
严谨定义：把观测估计对照经验零分布（而非标准正态）计算的双侧 p 值，检验"校准后效应是否可区分于零"。p > 0.05 = 扣除偏倚后无证据支持真实效应；p < 0.05 = 扣除偏倚后仍有可区分的效应。
🚦 通俗解释：它是一个二元开关——只回答"扣除偏倚后是否有证据支持真实效应"。BF 则是一个连续刻度，量化偏倚占校准后信号的比例。两者互补：论文应同时报告。
⑤ 三区分类 Three-zone classification
严谨定义：基于 BF（等价于 BER）的启发式分区，CI 跨区时取更谨慎的一侧：
效应主导 effect-dominated：BF < 1/3（残留效应 ≥ 偏倚 2 倍） 混合区 mixed：1/3 ≤ BF ≤ 0.5（偏倚与效应混在一起，难分彼此） 偏倚主导 bias-dominated：BF > 0.5
🎯 通俗解释（三色仪表盘）：绿灯区（效应主导）"信号盖过噪声，可谈疗效"；黄灯区（混合）"偏倚与效应混在一起、势均力敌，必须谨慎 + 做敏感性分析"；红灯区（偏倚主导）"这份数据不足以支持因果结论"。注意：红灯 ≠ 药物无效，只是"这份数据里分不清效应与偏倚"。
⑥ Fieller 置信集 Fieller confidence set
严谨定义：对带符号比值 ρ = μ̂B/ψ̃ 的置信集，由不等式 (m₁−ρm₂)² ≤ z²α/2(v₁₁−2ρv₁₂+ρ²v₂₂) 定义。当分母 ψ̃ 太小时，它会诚实地退化为外集、空集或全直线。
🪞 通俗解释：普通区间在分母趋近 0 时可能给出误导性的有限区间；Fieller 集则对该比值给出诚实的置信区域——该多宽就多宽，该无界就无界。β 受体阻滞剂病例的 Fieller 集为 (−∞, −1.62]∪[1.45, ∞)，意思是"比值只能排除中间一小段，其余全都与数据相容"——这正是"校准后效应≈0"时该有的诚实回答。
⑦ bootstrap 中位数点估计 Bootstrap-median point estimate
严谨定义：在 logit（BF）/ log（BER）尺度取 bootstrap 分布的中位数再反变换。点估计与置信区间出自同一个分布，因此点估计不可能落在自己的 CI 之外。
🔧 通俗解释：v33 曾出现过"点估计 413.2 > 自己的 CI 上限 204.8"的怪象（原始比值与 bootstrap 分布脱节）。改用中位数后，这种自相矛盾从机制上被消除。
三区阈值为什么是 1/3 和 1/2？它们对应"残留效应 ≥ 偏倚的 2 倍"与"偏倚 ≥ 残留效应"两个可理解的界限（在 BER 尺度即 0.5 与 1）。这是启发式而非决策理论推导；且刻意不对称——观察性研究中误认因果的代价 > 过度谨慎的代价，所以红灯区留得更宽。

⑥ 病例研究（MIMIC-IV） The beta-blocker case study

负对照的偏倚分布特征：漏斗图 The negative-control fingerprint

每个灰点是一个负对照（横轴 = 估计的 log RR，纵轴 = 标准误；横线 = 95% CI）。深色阴影带 = 拟合的经验零分布 95% 区域；虚线 = 平均偏倚 μ̂B = −0.190。红菱形 = 未校准主估计，绿菱形 = 校准后主估计（数值见右上角图例，悬停灰点可看每个负对照的细节）。注意 12 个负对照几乎全部落在 0 的左侧（保护性方向）：研究设计会系统性地把估计向保护方向偏移。

校准前后：效应去哪了？ Before vs after calibration

每一行是一个估计：深红 = 未校准（naive），深绿 = 校准后（calibrated）；点 = RR 点估计，横线 = 95% CI，虚线 = RR = 1（无效）。校准把 β 受体阻滞剂的 RR 从 0.83 移到 1.01（校准 p = 0.94）——"降低 17% 死亡"的保护性关联在校准后完全消失；而 GDMT 的 RR 0.65 校准后仍为 0.78（校准 p = 0.007），真实的多药获益经受住了同一套偏倚校准。这正是 BF 要量化的差别。

这一节在问什么、答什么："偏倚主导"这个结论，会不会是某个具体设定的偶然产物——比如恰好某个负对照在捣乱、恰好某套模型库不合适、恰好宽限期选得不巧？答案：不会，结论在这些扰动下保持稳定。四种扰动（换掉任意一个对照、换模型库、换宽限期、检查对照的正态性）之下，β 受体阻滞剂的 BF 始终留在红灯区（0.80–0.99），分区结论一次都没有改变。因此"偏倚主导"的判定不是由某一特定设定导致的偶然结果，而是稳健的结论。

⑦ 模拟研究：这个指标靠得住吗？ Simulation: does the metric work?

结论速览：靠得住——但只在其承诺的范围内。模拟（336 条件 × 200 次重复 = 67,200 次分析）显示：BF 分类在两端可靠（红灯区 80.0%、绿灯区 95.1%），在中间不可靠（黄灯混合区仅 41.8%，仅略高于随机猜测（33.3%）。因此 v34 的规则是：两端可以下结论，中间诚实地说"分不清"——改用"CI 完全落进某区才判定"的选择性规则后，凡是能下结论的，正确率 86.8%（但只覆盖 47.6% 的情形）。换句话说：它能可靠地认出"明显偏倚主导"和"明显效应主导"，对"中间地带"不强行判定。

设计：析因模拟，五个因子：真实效应 ψ（7 档）、系统偏倚 μB（6 档）、偏倚异质性 σB（2 档）、负对照数 K（12/25）、偏倚交换性违反比例（0%/30%）。每次重复都拟合经验零、算 BF、做三区分类，并与 OHDSI 校准 p 值及"不校准"两种策略对照。

三区分类准确率 Zone classification accuracy

三分类的随机猜测水平是 33.3%（虚线）。红灯区与绿灯区表现可靠；黄灯混合区只有 41.8%——这是比值类指标在"分母（校准后效应）接近 0"时的内在极限。v34 的应对：黄灯区不做点估计判断，改用"CI 完全落进某区才下结论"的选择性规则（见下）。

有界尺度的红利：偏倚从 +319% 缩到 +2% Why the bounded scale matters

"相对偏倚"指估计值对真实值的平均偏离程度（0 = 无偏）。BER（无界比值）在交换性成立时高估 137%–319%；换成有界 BF 后只有 +1.8%–2.3%。代价：交换性被违反（30% 对照偏倚被平移 +0.15）时，BF 会向 0.5 衰减（−30% 左右）——方向是"乐观"的，所以接近阈值的 BF 必须结合对照质量解读。

分类准确率热图：坏区在"对角线" Accuracy heatmap

单元格 = 该 (真实效应 ψ, 系统偏倚 μB) 组合在 8 个配置（σB×K×违反）×200 次重复上的平均分类准确率（%）。悬停查看细节。
沿对角线（|μB| ≈ |ψ|，即 BF真 ≈ 0.4–0.5）准确率跌到 14%–56%：偏倚与效应混在一起时最难分。远离对角线（要么偏倚碾压、要么效应碾压）准确率高——与直觉一致，也与三区条形图一致。

CI 启发式：选择性分类器 The CI-based selective classifier

规则：只有当整个 95% CI 完全落进红灯区或绿灯区才下"决定性"结论，否则一律判黄灯（"证据不足"）。
模拟结果：67,200 次重复中仅 47.6% 能下决定性结论，但其中 86.8% 正确（黄灯区准确率升到 81.9%，红灯 57.5%、绿灯 75.5%）。K 从 12 增至 25，决定性比例从 43.7% 升到 51.6%。
临床含义：黄灯 = "分不清"，不是"相等"。应报告"证据不足"，而不强行给出判定。

⑧ 如何应用 How to use it in practice

四步读法 A four-step reading

  1. 看负对照的分布特征：负对照是否整体偏向一个方向？（是 → 系统偏倚存在；否或双向 → 谨慎，μ̂B 可能被稀释。）
  2. 看校准后效应与校准 p：校准后效应还剩多少？是否可区分于零？（校准 p > 0.05 = 扣除偏倚后无证据支持真实效应；校准 p < 0.05 = 仍有可区分的效应。）
  3. 看 BF 及其 CI：CI 完全在红灯区（BF>0.5）→ 不能作因果解读；完全在绿灯区（BF<1/3）→ 信号盖过偏倚；跨区/黄灯 → 证据不足，不强行判定。
  4. 看敏感性：留一法、模型设定、宽限期是否改变分区；Fieller 集是否无界（分母太小时必须诚实）。

论文报告模板 A reporting template

"在 12 个负对照结局的校准下，β 受体阻滞剂与 1 年全因死亡的校准后 RR 为 1.01（95% CI 含 1；校准 p = 0.94，即扣除偏倚后无证据支持真实效应）。经验零分布的平均系统偏倚 μ̂B = −0.190（log RR 尺度），偏倚分数 BF = 0.91（95% CI, 0.74–0.99），落入偏倚主导区——系统性偏倚约占校准后总信号的九成。该观测关联与"健康依从者混杂主导"一致；本方法学示范不构成 β 受体阻滞剂对 1 年死亡无效的证据。"

常见误读清单 Misreadings to avoid

✗ "BF = 0.91 说明效应只剩 9%。"错。BF 的"份"是偏倚与残留效应两者合计的份，不是对真实效应的估计。
✗ "红灯区 = 药物无效。"错。红灯 = "这份观测数据不足以支持因果结论"。
✗ "BF 接近 1，所以偏倚精确占 97%。"错。接近 1 是"饱和"信号，数值只作数量级读。
✗ "黄灯（混合区）说明偏倚与效应真的各占一半。"错。黄灯 = "分不清"，不是"相等"。

⑨ 术语表 Glossary

偏倚分数 · Bias Fraction (BF)
|μ̂B| / (|μ̂B| + |ψ̃|) ∈ [0,1]。校准后总信号中系统偏倚所占份额。Share of the calibrated signal attributable to systematic bias.
偏倚效应比 · Bias-Effect Ratio (BER)
|μ̂B| / |ψ̃| = BF/(1−BF)。同一信息的无界比值形式。Bias expressed as a multiple of the residual effect.
观测偏倚分数 · Observed Bias Fraction (OBF)
|μ̂B| / |ψ̂obs|。偏倚占未校准关联的份额。Bias as a share of the uncalibrated association.
三区分类 · Three-zone classification
偏倚主导（BF>0.5）/ 混合区（1/3–0.5）/ 效应主导（BF<1/3）。bias-dominated / mixed / effect-dominated.
负对照 · Negative control
共享混杂结构、但治疗无法因果影响的结局。An outcome that cannot be caused by the exposure but shares its confounding structure.
经验零分布 · Empirical null distribution
由负对照估计拟合的偏倚分布 N(μ̂B, τ̂k²+σ̂B²)。The bias distribution estimated from negative controls.
偏倚交换性 · Bias exchangeability
主估计与负对照共享同一偏倚分布的假设。The assumption that the primary estimate and the controls share one bias-generating process.
校准 p 值 · Calibrated p-value
对照经验零分布（而非标准正态）计算的 p 值；p>0.05 = 扣除偏倚后无证据支持真实效应。A p-value computed against the empirical null instead of the standard normal.
目标试验模拟 · Target trial emulation (TTE)
用观察数据显式模拟一个假想随机试验的设计。Designing an observational study to mimic a hypothetical randomized trial.
TMLE
目标最大似然估计，双重稳健的半参数因果估计方法。Targeted maximum likelihood estimation.
Fieller 置信集 · Fieller confidence set
比值 μ̂B/ψ̃ 的置信集；分母近零时诚实地变为外集/无界。Confidence set for a ratio that degrades honestly when the denominator is near zero.
健康依从者效应 · Healthy adherer effect
依从治疗者结局更好、即使治疗本身无效的现象。Better outcomes among adherers regardless of treatment efficacy.
